# 独立注釈者向け

この資料は文章の関係を注釈する手順確認です。AI作者判定を行う試験ではありません。
本文は匿名のQ番号です。原作品の一部、別の版、実験のための編集を含む可能性がありますが、どの型があるかだけで問題にしないでください。

1. 運用者が割り当てた本文だけを読みます。モデル出力、別の注釈者の票、編集の狙いは見ません。
2. 問題となる関係、または機能として働く関係を、完全一致の短い引用と位置で記録します。両側が必要な関係なら二つの引用を使います。
3. 対象、時点、条件、話者／引用の層を確認します。未提示の結末や既知の作品情報を勝手に補いません。
4. 問題が見つからなかった場合も「読了・0関係」と明示して完了時刻を記録します。白紙の票と区別します。
5. 価値判断の分岐、資料不足、基準の曖昧さ、読み落としを分けます。「効果的とは思わない」だけを問題関係にしません。
6. 所要時間と、以前読んだ作品か、別版を先に見たか、規約設計への関与をnotesへ残します。

票のinput_idにはQ番号を使います。運用者は対応する正式IDへ置換し、引用・判断・時間を変更しません。変換後の票をあなたが確認してからハッシュ・完了記録・ロックを確定します。

役割は規約の設計に関わっていない人がindependent、設計者がdeveloper、LLMがllm。LLMの票を人間の独立注釈へ置き換えないでください。
2名の票を各自で確定した後に、裁定者が突き合わせます。

`forms/Qxxx.csv`を注釈者ごとに別々のコピーへ記入します。列の説明は`COLUMNS.md`、項目の定義と安全弁は`ITEM-DEFINITIONS-rc.3.md`を参照してください。モデル出力や期待関係は含まれていません。読了を`forms/completions.csv`へ別記し、0関係と未着手を区別します。
