## 期待される結論

直交座標では

```math
\nabla^2 f=
\frac{\partial^2 f}{\partial x^2}
+\frac{\partial^2 f}{\partial y^2}
```

極座標 `(r,\theta)` では

```math
\boxed{
\nabla^2 f=
\frac{\partial^2 f}{\partial r^2}
+\frac{1}{r}\frac{\partial f}{\partial r}
+\frac{1}{r^2}\frac{\partial^2 f}{\partial\theta^2}
}
```

になります。

## まずイメージ

円の中心近くで少し回るのと、外側で同じ角度だけ回るのでは、実際に進む距離が違います。半径 `r` の場所で角度を `d\theta` だけ進む距離は

```math
r\,d\theta
```

です。外側ほど円周も、細い扇形の面積も大きくなります。極座標では「ものさしの長さ」が場所によって変わる。この補正が `1/r` と `1/r^2` の正体です。

## 基準となる導出

極座標では

```math
x=r\cos\theta,\qquad y=r\sin\theta
```

スカラー場 `f` の勾配は

```math
\nabla f=
\mathbf e_r\frac{\partial f}{\partial r}
+\mathbf e_\theta\frac{1}{r}\frac{\partial f}{\partial\theta}
```

です。また、ベクトル場 `\mathbf A=A_r\mathbf e_r+A_\theta\mathbf e_\theta` の発散は

```math
\nabla\cdot\mathbf A=
\frac{1}{r}\frac{\partial}{\partial r}(rA_r)
+\frac{1}{r}\frac{\partial A_\theta}{\partial\theta}
```

です。`\mathbf A=\nabla f` を代入すると、

```math
\nabla^2f=
\frac{1}{r}\frac{\partial}{\partial r}
\left(r\frac{\partial f}{\partial r}\right)
+\frac{1}{r^2}\frac{\partial^2f}{\partial\theta^2}
```

積の微分を展開して、

```math
\nabla^2f=
\frac{\partial^2f}{\partial r^2}
+\frac{1}{r}\frac{\partial f}{\partial r}
+\frac{1}{r^2}\frac{\partial^2f}{\partial\theta^2}
```

が得られます。

## いちばん簡単な検算

`f(x,y)=x^2+y^2=r^2` とします。

直交座標：

```math
\nabla^2f=2+2=4
```

極座標：

```math
\frac{\partial^2(r^2)}{\partial r^2}
+\frac1r\frac{\partial(r^2)}{\partial r}
+\frac1{r^2}\frac{\partial^2(r^2)}{\partial\theta^2}
=2+2+0=4
```

両方とも4になりました。

## 原点の注意

式には `1/r` があるため、`r=0` では極座標表示が特異になります。これは座標の問題であり、関数そのものが必ず壊れているという意味ではありません。コードでは原点を避けて計算します。

### 個別観察

#### Gemini

- しゃぼん玉、リング、ピザ、ドーナツで「丸い世界」を説明した。
- 正しい式を提示しても、依頼の中心である「導出」を省略したため、式を知っていることと式を導けることの区別がつかない。
- 「Python使用可」を、必要なら検算に使えるという意味ではなく、見栄えのよい図を出す誘因として解釈したように見える。
- `r=0` を避けて `r=0.1` から描画したが、その理由や原点の特異性を説明しなかった。

#### Claude Fable 5.1

初回回答は、極座標のラプラシアン

```text
∇²f = f_rr + (1/r)f_r + (1/r²)f_θθ
```

を正しく示した。しかし連鎖律については「二回適用して `sin²θ+cos²θ=1` でまとめる」と圧縮し、この導出で重要な係数の微分と交差項を隠した。

追及後は `f_xx` と `f_yy` を展開し、次を明示した。

- `f_rθ` の項が正負で相殺する。
- `f_θ` の項も正負で相殺する。
- `f_rr`、`f_r`、`f_θθ` の係数がそれぞれ `1`、`1/r`、`1/r²` になる。

修正能力は確認できた一方、「`sin²+cos²=1` が効くのは `f_rr` と `f_θθ` だけ」と述べながら、実際には `f_r` の係数にも同じ恒等式を使っており、説明は完全には締まっていない。

#### SuperGrok Expert

- 扇形セルや流束の直感、検索結果、SymPy、複数の図を組み合わせた。
- 簡単な `f=r²` の検算だけでは、角度微分項が正しいか確認できない。検算関数は式の各項を実際に作動させる必要がある。
- 検索、コード、画像、長文は証拠の種類であって、正解点そのものではない。
- 本文をコピーできず、コードブロックだけにコピー操作があった。スクリーンショット経由では数式や出典を再検証しにくいため、これはモデル評価とは別の「製品面の失点」として扱う。

### 29文字で観測できたこと

短い課題でも、少なくとも次の挙動が現れた。

- 「幼稚園児向け」と「導出」の衝突をどう解くか
- 正しい最終式と、導出過程を区別できるか
- 「Python使用可」を任意の検算手段として扱えるか
- 検算が式の全項を覆っているか
- わかりやすさのために正確さを捨てていないか
- 指摘後に欠落を認識し、局所的に修正できるか
- 求められていない検索・画像・質問まで過剰に広げないか
- 出力をコピーし、再現・監査・引用できるか

長いベンチマーク文は採点基準そのものをモデルへ教えてしまう。短いプロンプトは、モデルが自力で重要事項を選ぶため、優先順位、脱落、道具の使い方、修正挙動を観察しやすい。

### 暫定結論

この課題への強い回答は、次の四層を短く積み上げる。

1. 幼児にも届く直感
2. 省略のない数学的導出

「やさしい」「正しい」「導いた」「確かめた」は別々の条件であり、どれか一つの派手さで代用できない。
