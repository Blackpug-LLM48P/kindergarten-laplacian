# MSF（Metaphor-Structure Fidelity）ルーブリック

対象は「幼稚園児にわかる極座標ラプラシアンの導出」への 1 回答。**良し悪しの総合点はつけない。**
比喩が数学の構造をどこまで運んでいるかだけを、下の 4 軸で観測する。

判定の前提となる数学的構造:
- 角度方向の 1 歩は長さ r·Δθ。外側ほど同じ角度でも遠い（伸びの非対称性）。これが 1/r² の由来。
- 半径方向には「外側ほど輪が大きい（円周 2πr）」ことによる f_r/r の補正が出る。
- 最終形: f_rr + (1/r) f_r + (1/r²) f_θθ、r = 0 は座標の特異点。

## stretch_level（0–3）

半径方向に伸びる非対称性（外側ほど角度 1 歩が長い／輪が大きい）が、どの層まで比喩に反映されているか。

| 値 | 基準 |
|---|---|
| 0 | 比喩がない、または比喩が非対称性に触れない（「丸い」だけ） |
| 1 | 本文の比喩で非対称性を言うが、式・図には結びつけない |
| 2 | 比喩の非対称性を式（r·Δθ、1/r、1/r² のいずれか）に明示的に対応づける |
| 3 | 比喩・図（またはコードによる描画）・式の 3 つで同じ非対称性を一貫して示す |

## drift（真偽）

比喩が途中で別物にすり替わり、前の比喩で立てた対応が引き継がれないか。
複数の比喩を**並べる**だけでは drift ではない。同じ説明の途中で主比喩が入れ替わり、対応関係が失われる場合に真。

## mismatch（真偽）

比喩と図・式の対応が崩れているか。例: 比喩では「半径方向に伸びる」と言いながら式では角度項の説明に使う、
ピザの切れ目（放射線）を等高線のように扱う、図の中の距離と本文の距離が食い違う。

## overextension（真偽）

比喩を数学が支えない範囲まで引っ張っていないか。例: 「ピザの面積が増えるから 1/r²」のように比喩だけで係数を導いたと主張する、
「トランポリンのへこみ＝ラプラシアン」を符号や規格化なしに等式として扱う。

## 根拠スパン

真と判定した軸、および stretch_level ≥ 1 には、回答本文から**そのまま**切り出した引用（evidence）を最大 3 つ付ける。
言い換えや要約は不可。本文にない文字列は機械的に弾かれる。
