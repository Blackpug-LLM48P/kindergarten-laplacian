極座標 (r, \theta) のラプラシアンは、「まあるいバウムクーヘンの上で、自分の場所がまわりよりどれくらいヘコんでいるか（シロップがどれだけ集まってくるか）」を測る魔法の虫眼鏡です。
数式で書くと、次の3つのパーツの足し算になります。
なぜこの3つのパーツが出てくるのか、「幼稚園のおやつの時間（バウムクーヘンとシロップ）」のイメージから出発して、最後にPythonで自動導出してみましょう。
1. まずは「ラプラシアン（\Delta）」ってなに？
ホットケーキの上にシロップをたらすところを想像してください。
 * 自分が立っている場所が、まわりよりヘコんでいる（谷になっている）と、まわりからシロップが流れ込んできます（\Delta f がプラス）。
 * 自分の場所が、まわりより盛り上がっている（山になっている）と、シロップは外へ逃げていきます（\Delta f がマイナス）。
つまりラプラシアン \Delta f とは、「前後・左右の4方向から、自分のところにどれだけシロップが流れ込んでくるか（＝どれくらいヘコんでいるか）」を合計したものです。
四角いワッフル（直交座標 x, y）なら、すべての部屋の大きさが同じなので、シンプルに「タテの曲がりぐあい」と「ヨコの曲がりぐあい」を足すだけです。
2. 幼稚園児にわかる！まあるいバウムクーヘン（極座標）の3つのヒミツ
今度は四角いワッフルではなく、まあるいバウムクーヘンを輪切りと放射線状にカットして、小さな1切れ（自分の部屋）を作ります。
極座標では、場所を次の2つで決めます。
 * r（アール）： 真ん中から、外に向かって何歩進んだか（まっすぐ方向）
 * \theta（シータ）： ぐるっと何歩まわったか（ぐるぐる方向）
バウムクーヘンの1切れを上からじっと見てみると、四角いワッフルとは違う2つのフシギなことに気づきます。
ヒミツ①：外側のカベのほうが広い！（\frac{1}{r}\frac{\partial f}{\partial r} がつく理由）
バウムクーヘンの1切れは、真ん中に近い「内側のカベ」よりも、外に向いた「外側のカベ」のほうが長くて広いですよね。
 * まっすぐ方向の曲がりぐあいそのものは \frac{\partial^2 f}{\partial r^2} です。
 * でも、外側の窓のほうが広いぶん、「外側の傾き（\frac{\partial f}{\partial r}）の影響が、内側の窓よりちょっとだけ多く入ってくるよ！」というおまけがつきます。そのおまけが \frac{1}{r}\frac{\partial f}{\partial r} です。
ヒミツ②：外側に行くほど1歩がビヨーンと伸びる！（\frac{1}{r^2} で割る理由）
みんなで手をつないで、メリーゴーランドみたいにぐるぐる回ることを考えます。
 * 真ん中の近く（r が小さい）だと、角度を1歩（d\theta）進んでも、ほんのちょびっとしか動きません。
 * でも、外側の端っこ（r が大きい）に行くと、同じ角度1歩（d\theta）なのに、実際のヨコの長さは r 倍にビヨーンと伸びます。
 * 「ヨコの1歩が r 倍に伸びたなら、1回目の変化（傾き）で \frac{1}{r} 倍、2回目の変化（曲がりぐあい）でもう1回 \frac{1}{r} 倍して、合計 \frac{1}{r^2} で割ってあげよう！」というのが \frac{1}{r^2}\frac{\partial^2 f}{\partial \theta^2} です。
3. シロップの出入りを数える「1分導出」
上のバウムクーヘンのお話を、そのまま算数（微積分）にしてみましょう。教科書の「合成関数の微分」でゴリゴリ計算するより、シロップの出入りを数えるほうが圧倒的にカンタンです。
バウムクーヘンの小さな1切れは、次のようなサイズをしています。
 * 奥行き（まっすぐ方向）： dr
 * 横幅（ぐるぐる方向）： r\,d\theta
 * 部屋の広さ（面積）： \text{たて} \times \text{よこ} = r\,dr\,d\theta
 * まっすぐ方向（内側・外側）のシロップの出入り
   シロップが流れるスピード（傾き \frac{\partial f}{\partial r}）に、カベの広さ（r\,d\theta）を掛けたものが「通るシロップの量」です。内側と外側の差をとると、カベの広さ r も一緒に変化するため、積の微分ルールから2つの項が出てきます。

 * ぐるぐる方向（右・左）のシロップの出入り
   横方向の実際の距離は r\,d\theta なので、傾きは \frac{1}{r}\frac{\partial f}{\partial \theta} です。これに横のカベの広さ（dr）を掛けて、右と左の差をとります。

 * 合計して「部屋の面積（r\,dr\,d\theta）」で割る！
   1と2を足して、部屋の面積 r\,dr\,d\theta で割り算すると、極座標のラプラシアンが完成します。

4. Pythonに「正面突破の微分計算」を全部やってもらおう！
もし学校のテストや大学のレポートで「x = r\cos\theta, y = r\sin\theta から合成関数の微分（Chain Rule）を使って真面目に導出しなさい」と言われたら、手計算だと \sin\theta と \cos\theta だらけになって泣きたくなります。
そこで、Pythonの数式処理ライブラリ SymPy に、ただの座標のルール（x = r\cos\theta, y = r\sin\theta）だけを教えて、最初から最後まで全自動で導出させてみましょう。
import sympy as sp

# 1. 変数と関数の準備（r: まっすぐの距離, theta: 角度）
r, theta = sp.symbols("r theta", real=True, positive=True)
f = sp.Function("f")(r, theta)

# 2. 極座標と直交座標(x, y)のルールだけを教える
x = r * sp.cos(theta)
y = r * sp.sin(theta)

# 3. ヤコビ行列 J を作って逆行列をとる（∂r/∂x, ∂r/∂y, ∂θ/∂x, ∂θ/∂y を自動計算！）
J = sp.Matrix(
    [[sp.diff(x, r), sp.diff(x, theta)], [sp.diff(y, r), sp.diff(y, theta)]]
)
J_inv = sp.trigsimp(J.inv())

dr_dx, dr_dy = J_inv[0, 0], J_inv[0, 1]
dtheta_dx, dtheta_dy = J_inv[1, 0], J_inv[1, 1]

print("--- 1階微分の変換パーツ（Pythonが自動導出） ---")
print(f"∂r/∂x = {dr_dx},  ∂r/∂y = {dr_dy}")
print(f"∂θ/∂x = {dtheta_dx}, ∂θ/∂y = {dtheta_dy}\n")


# 4. x方向の微分 (∂/∂x) と y方向の微分 (∂/∂y) を関数にする
def d_dx(expr):
  return dr_dx * sp.diff(expr, r) + dtheta_dx * sp.diff(expr, theta)


def d_dy(expr):
  return dr_dy * sp.diff(expr, r) + dtheta_dy * sp.diff(expr, theta)


# 5. ワッフルのラプラシアン Δf = ∂²f/∂x² + ∂²f/∂y² を計算して整理！
laplacian_polar = sp.expand(sp.trigsimp(d_dx(d_dx(f)) + d_dy(d_dy(f))))

print("--- 完成した極座標ラプラシアン ---")
sp.pprint(laplacian_polar)
