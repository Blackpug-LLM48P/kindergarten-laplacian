# 回答の数学的検証と説明レビュー

## 対象と条件

対象は [answer-original.txt](answer-original.txt) の貼付回答。以下の式はレビュー側の補足であり、対象回答の一部ではない。関数は局所的に2回連続微分可能、極座標の式は `r>0` で扱う。

## 1. 直交座標からの独立導出

```math
\partial_x=\cos\theta\,\partial_r-\frac{\sin\theta}{r}\partial_\theta,
\qquad
\partial_y=\sin\theta\,\partial_r+\frac{\cos\theta}{r}\partial_\theta.
```

係数自身の微分も含めて二度適用し、混合微分をまとめると、

```math
(\partial_x^2+\partial_y^2)u
=u_{rr}+\frac1r u_r+\frac1{r^2}u_{\theta\theta}.
```

保存コードは `r^n exp(ikθ) ∂r^a ∂θ^b u` の形式で連鎖律と積の微分を展開する小さな形式計算を実装し、上式と一致することを検査する。これはSymPyによる検証ではない。本計算で現れる係数は小さな二進有理数で、複素浮動小数点として正確に表現でき、形式計算部分の一致判定には数値許容誤差を使わない。混合微分の交換可能性はC²の仮定に依存する。

対象回答の最終式および半径方向のフラックス差分は、この式と整合する。

## 2. 独立した具体例

極座標側を有限差分、直交座標側を解析的に計算した値で比較する。刻みは `h=1e-4`、点は `(r,θ)=(0.7,0.3),(1.2,1.1),(2,-1)`。絶対誤差の許容値は `1e-4`。

| 関数 `u(x,y)` | 直交座標の `Δu` |
|---|---|
| `3` | `0` |
| `x+2y` | `0` |
| `x²+y²` | `4` |
| `x²-y²` | `0` |
| `x⁴+y⁴` | `12(x²+y²)` |
| `x³y²+2xy+y⁴` | `6xy²+2x³+12y²` |
| `exp(x)+sin(y)` | `exp(x)-sin(y)` |

21地点の比較はすべて通過。最大絶対誤差は約 `6.55e-7`。角度依存のある例を含み、半径のみの `r²` に検算を限定しない。有限個の数値例だけで恒等式を証明したことにはせず、一般式の形式計算と区別する。

## 3. 有限の扇形で流束を照合

```math
u=r^4+r^2\cos(2\theta)+r\sin\theta
=(x^2+y^2)^2+x^2-y^2+y.
```

直交座標から `Δu=16(x²+y²)=16r²`。領域 `1≤r≤2, 0≤θ≤π/3` における面積積分は `20π`。四辺を通る勾配の外向き流束を合成Simpson則（各辺600分割）で求め、これと照合した。差は約 `2.17e-12`、許容値 `1e-8` を満たす。関数の角度依存は調和成分であり、左右の流束が消えるのではなく、角度依存成分の半径方向の寄与と相殺する。

## 4. 冒頭の符号説明への反例

対象回答の「自分の場所が、まわりより低いと、ラプラシアンはプラス」は厳密には成り立たない。

```math
u=x^4+y^4,\qquad \Delta u=12x^2+12y^2.
```

原点は厳密な最小点であり、他のすべての点より低いが、`Δu(0,0)=0`。C²関数の局所最小点では `Δu≥0` であり、必ず正とは限らない。逆に `u=x²-y²` は鞍型でも `Δu=0`。原文は「ゼロなら平ら」と明記していないため、その命題を直接引用したとは扱わないが、単なる周囲との高低差で符号を説明する表現には誤読の余地がある。

正確な直感は「ごく近くの円周上の平均と自分の高さの差を、距離の2乗で割った極限」である。点 `p` の周りの半径 `ε` の円周平均を `Mεu(p)` とすると、

```math
\Delta u(p)=\lim_{\varepsilon\to0}
\frac4{\varepsilon^2}\left(M_\varepsilon u(p)-u(p)\right).
```

## 5. 省略された角度方向の導出

原文は接線方向の坂の急さ `uθ/r` までは説明するが、その後を「こちらも…面積で割ると」で省略する。薄いセルの代表半径を `r` とした先頭次数の差分は、

```math
\frac{
\left[\frac1r u_\theta(r,\theta+\Delta\theta)
-\frac1r u_\theta(r,\theta)\right]\Delta r
}{r\Delta r\Delta\theta}
\longrightarrow\frac1{r^2}u_{\theta\theta}.
```

接線方向の勾配に一つ、面積で割るときにもう一つ `1/r` が現れることを説明すると、係数の由来が追える。有限のセルに対する厳密な式では左右の辺に沿った半径積分を使い、上式はその微小セル近似である。

## 6. 面積・原点・対象読者

- 扇形セルの厳密な面積は `(rΔr+(Δr)²/2)Δθ`。原文の `≈rΔrΔθ` は固定した `r>0` での先頭次数として正しい。
- `r=0` をそのまま代入できないという注意は適切。直交座標でC²に延長できる場合、ラプラシアン全体の極限は原点の値に一致する。各項の極限が個別に存在するとは限らず、任意の関数で原点の極限が存在するわけでもない。
- ピザ、辺の長さ、坂の矢印は直感への入口になる。一方、偏微分・極限・流束の説明は幼児が実際に理解したか未検証。「幼児向け」を達成したという実証評価は行わない。
- 対象回答は具体例による検算や実行コードを示していない。非表示の処理まで否定する根拠はない。後続の本検証は対象回答へ遡及して加点しない。
