1. 幼稚園児でもわかる「極座標ラプラシアン」のお話
まず、むずかしい言葉をやわらかくします。
 * ラプラシアン（\Delta）：
   「いま自分がいる場所が、まわりのみんなと比べてどれくらい『へこんでる』か『でっぱってる』か」を調べる虫めがねのことです。トランポリンの真ん中に乗ってへこんでいるとき、ラプラシアンは大きくなります。
 * ふつうの座標（x, y）：
   しょうぎ盤みたいな四角いマス目の世界です。どこへ行ってもマスの大きさが同じなので、前・うしろ・右・左の4人と比べるだけで、へこみ具合がわかります。
 * 極座標（r, \theta）：
   丸いピザ（またはバームクーヘン）の世界です。「真ん中からどれくらい遠いか（r）」と、「ぐるっとどれくらい回ったか（\theta）」で場所を決めます。
なぜピザの世界だと計算がかわるの？
ピザを切ると、真ん中に近いところはせまく、外側に行くほどどんどん広くなりますよね。
だから、四角いマス目と同じように「おとなりさん」と比べようとすると、2つの「ちがい」を直してあげないといけません。
 * 外に行くほど、お部屋が広くなる（\frac{1}{r} のおまけ）
   外に向かって1歩すすむと、横幅がぐーんと広がります。その広がりぶんの「おまけ」を足してあげる必要があります。
 * 外側でぐるっと回ると、1歩がすごく長くなる（\frac{1}{r^2} のわり算）
   同じ「ちょっとだけ回転」でも、真ん中だと少ししか動かないのに、外側だとすごく遠くまで動いてしまいます。だから、遠いぶんだけ割り算してサイズをそろえます。
これを合体させると、ピザの世界の虫めがね（極座標ラプラシアン）が完成します。
2. Python（計算ロボット）に導出させてみよう
四角いマス目 (x, y) のルールを、丸いピザ (r, \theta) のルールに書き換える手計算は、大人でも少し大変です。そこで、Pythonの記号計算ライブラリ SymPy に「連鎖律（チェインルール）」をそのまま解かせます。
import sympy as sp

# 1. 使う文字（変数）を用意する
# r: 真ん中からの距離（プラスの数）, theta: 角度
r, theta = sp.symbols('r theta', real=True, positive=True)

# 調べたい関数 f(r, theta) を定義
f = sp.Function('f')(r, theta)

# 2. マス目(x, y) と ピザ(r, theta) の関係から、
#    「xやyで少し動かすと、rとthetaはどう動くか」の変換ルールを作る
#    x = r*cos(theta), y = r*sin(theta) より：
dr_dx = sp.cos(theta)
dtheta_dx = -sp.sin(theta) / r

dr_dy = sp.sin(theta)
dtheta_dy = sp.cos(theta) / r

# 3. 1回微分する演算子（x方向・y方向の傾きを、rとthetaで表す）
def d_dx(expr):
    return sp.diff(expr, r) * dr_dx + sp.diff(expr, theta) * dtheta_dx

def d_dy(expr):
    return sp.diff(expr, r) * dr_dy + sp.diff(expr, theta) * dtheta_dy

# 4. 2回微分して足し合わせる（ラプラシアン: ∂²f/∂x² + ∂²f/∂y²）
d2f_dx2 = d_dx(d_dx(f))
d2f_dy2 = d_dy(d_dy(f))

laplacian_polar = sp.simplify(d2f_dx2 + d2f_dy2)

# 5. 結果を表示する
print("極座標ラプラシアン:")
sp.pprint(laplacian_polar)

実行結果
極座標ラプラシアン:

───(f(r, θ))         ───(f(r, θ))
  2     ∂              2      
∂θ    r⋅──(f(r, θ))  ∂r       
        ∂r                    
──────────── + ─────────────── + ────────────
      2               2               1      
     r               r                       

整理すると、さきほどの式と完全に一致します。
コードの中の d_dx と d_dy を2回かけるだけで、面倒な三角関数の打ち消し合い（\sin^2\theta + \cos^2\theta = 1 など）を sp.simplify が全部自動で片付けてくれます。
