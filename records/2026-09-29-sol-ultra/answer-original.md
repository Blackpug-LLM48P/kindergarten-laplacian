よし。丸い砂場で導きます。
子どもには砂場の話をして、そのすぐ下に同じ話を数式で書きます。

まず、砂場のどこにいるかを教えてください。

「真ん中から、どれくらい離れている？」
「どっちを向いている？」

この二つが分かれば、場所が決まります。真ん中からの距離を r、向きを表す角度を \theta と呼びます。これが極座標です。

砂の高さは、場所によって違います。その高さを u(r,\theta) と書きます。

⸻

砂場に、小さな矢印を置きましょう。

矢印は「砂が高くなる向き」を向いています。急な坂なら長い矢印、平らなら長さゼロです。

小さな場所を囲んで、ふちを横切る矢印を調べます。

* 外へ向かう分は、足す。
* 中へ向かう分は、引く。
* 最後に、その場所の面積で割る。

囲む場所をどんどん小さくしたときの、この値がラプラシアンです。

お椀の底なら、どちらへ歩いても上り坂なのでプラス。山のてっぺんなら、どちらへ歩いても下り坂なのでマイナスになります。

普通の四角い場所で数えると、左右の坂の差と、上下の坂の差になるので、

\Delta u
=
\frac{\partial^2u}{\partial x^2}
+
\frac{\partial^2u}{\partial y^2}.

ここで \partial u/\partial x は「横に進むと高さがどれだけ増えるか」、もう一度微分したものは「その坂の強さがどれだけ変わるか」です。

同じ矢印を、今度は丸い砂場の切れ端で数えます。

中心から離れると、同じ角度でも道が長くなります。切れ端の外側の道は、内側より長いですね。

この切れ端の厚みを h、角度の幅を k とします。角度は「弧の長さ÷半径」で数えるラジアンを使うので、弧の長さは「半径×角度」です。

したがって、

\begin{aligned}
\text{外側の道}&=(r+h/2)k,\\
\text{内側の道}&=(r-h/2)k,\\
\text{切れ端の面積}&=rhk.
\end{aligned}

面積は「内外の道の平均の長さ×厚み」。この切れ端では、ぴったり一致します。

まず、中心から離れる方向の矢印を数えましょう。

その方向の坂の強さを

u_r=\frac{\partial u}{\partial r}

と書きます。

坂の強さが同じでも、出口が長ければ、外へ向かう矢印の合計は大きくなります。

小さい切れ端では、各ふちの坂を中央の値で代表させると、半径方向の「外へ出る分−中へ入る分」はおよそ、

(r+h/2)k\,u_r(r+h/2,\theta)
-
(r-h/2)k\,u_r(r-h/2,\theta).

面積 rhk で割り、切れ端をどんどん小さくすると、

\text{半径方向の分}
=
\frac1r\frac{\partial}{\partial r}(r u_r).

積 r u_r が変わるのには、二つの理由があります。

坂の強さが変わることと、道の長さが変わること。

それを分けて書くと、

\frac1r\frac{\partial}{\partial r}(r u_r)
=
\underbrace{u_{rr}}_{\text{坂の強さの変化}}
+
\underbrace{\frac1r u_r}_{\text{外側ほど道が長い分}}.

これで、見落としやすい \frac1r u_r が出ました。

⸻

次に、ぐるっと回る方向です。

同じ角度だけ向きを変えても、中心の近くなら少し歩くだけ。遠くなら、たくさん歩かなければいけません。

歩く距離は、

\text{距離}=r\times\text{角度の変化}.

だから、角度あたりの高さの変化を、歩いた距離あたりに直すには、r で割ります。

ぐるっと回る方向の坂の強さは、

\frac{u_\theta}{r},
\qquad
u_\theta=\frac{\partial u}{\partial\theta}.

切れ端の左右のふちから出入りする分を引き算し、面積で割ります。ふちの長さ h が消えて、

\frac{
(u_\theta/r)_{\theta+k/2}
-
(u_\theta/r)_{\theta-k/2}
}{rk}

という形に近づきます。切れ端を小さくすると、

\text{回る方向の分}
=
\frac1r\frac{\partial}{\partial\theta}
\left(\frac{u_\theta}{r}\right)
=
\frac1{r^2}u_{\theta\theta}.

坂を測るときに一回、その坂の変化を測るときにもう一回、角度を歩く距離に直した。
だから r で二回割るのです。

半径方向と回る方向を足して、完成です。

\boxed{
\Delta u
=
\frac{\partial^2u}{\partial r^2}
+
\frac1r\frac{\partial u}{\partial r}
+
\frac1{r^2}\frac{\partial^2u}{\partial\theta^2}
}
\qquad(r>0).

⸻

答え合わせに、高さが u=r^2 のお椀を使いましょう。

中心からの距離だけで高さが決まるので、ぐるっと回っても高さは変わりません。

u_r=2r,\qquad u_{rr}=2,\qquad u_{\theta\theta}=0.

代入すると、

\Delta u=2+\frac{2r}{r}+0=\boxed{4}.

縦横で書いても u=x^2+y^2 なので、答えは 2+2=4。一致します。

ここで「回っても高さは変わらないから、半径方向の u_{rr}=2 だけでいい」とすると間違います。円に沿って回ることと、横へまっすぐ歩くことは違うからです。横へまっすぐ歩けば、お椀の底から離れて上り坂になります。

Pythonでも、近くの値を使って確認できます。

def laplacian(u, r, theta, h=1e-4):
    center = u(r, theta)
    radial = (
        u(r+h, theta) - 2*center + u(r-h, theta)
    ) / h**2
    widening = (
        u(r+h, theta) - u(r-h, theta)
    ) / (2*h*r)
    angular = (
        u(r, theta+h) - 2*center + u(r, theta-h)
    ) / (r*r*h*h)
    return radial + widening + angular
print(round(laplacian(lambda r, theta: r*r, 2, 0.7), 6))
# 4.0

さらに5種類の形・計45点で縦横の式と照合し、最大絶対誤差は約 3.4\times10^{-7} でした。

なお、真ん中の r=0 では「どっち向き？」が決まりません。この式に直接ゼロを入れず、縦横の式で計算するか、滑らかな形なら式全体の極限を取ります。
