公園のお砂場にある「お山」や「へこみ」のぐあいを調べる魔法のルーペを、四角いマス目（デカルト座標）から、丸いケーキ（極座標）に持ち替えるお話だよ！
1. ラプラシアンってなに？（お山の「とんがり」チェック！）
お砂場にいろんな高さの場所があるとするね。
 * まわりの平均より、真ん中が低い（へこんでる・お皿みたい） \rightarrow プラス（＋）！お水がたまるよ。
 * まわりの平均より、真ん中が高い（とんがってる・お山みたい） \rightarrow マイナス（ー）！お水が流れていくよ。
 * まわりの平均とまったく同じ（まっすぐな坂道） \rightarrow ゼロ（0）！
この「まわりの平均と、真ん中の高さの差」を測る魔法の計算が ラプラシアン（\Delta） だよ！
2. 四角いマス目から、丸いケーキへお引越し！
ふつうは「タテ（y）」と「ヨコ（x）」の四角いマス目で測るけれど、丸いケーキや池の波紋を測るときは、「真ん中からのきょり（r）」と「ぐるっと回る角度（\theta）」を使ったほうが便利だよね。
でも、丸いケーキの切り分け方には「1つだけ特別なルール」があるんだ。
> 【ケーキのルール】
> 真ん中（中心）から遠くなるほど、同じ角度（\theta）で切っても、外側のほうが幅が広くなる！（だから、外側に行くほど角度の変化を r で割って小さく調整してあげる必要があるよ）
> 
これさえ覚えれば、あとはPython（パイソン）っていう賢いロボットに計算をおまかせしちゃおう！
3. Pythonロボットに計算してもらおう！
文字の計算が得意な SymPy（シンパイ）っていう道具を使って、タテ・ヨコの式から、丸いケーキの式へ一気に変身させるよ。
import sympy as sp

# 1. 文字（記号）を用意するよ
r, theta = sp.symbols('r theta', positive=True)  # きょり r と 角度 theta
f = sp.Function('f')(r, theta)                   # お砂場の高さ f(r, theta)

# 2. タテ(y)・ヨコ(x) と きょり(r)・角度(theta) の関係
# x = r * cos(theta), y = r * sin(theta) を逆向きに微分するための魔法（連鎖律）
dr_dx = sp.cos(theta)
dr_dy = sp.sin(theta)
dtheta_dx = -sp.sin(theta) / r
dtheta_dy = sp.cos(theta) / r

# 3. 「ヨコ(x)にちょっと進んだときの傾き」と「もう1回傾き（曲がりぐあい）」
df_dx = sp.diff(f, r) * dr_dx + sp.diff(f, theta) * dtheta_dx
d2f_dx2 = sp.diff(df_dx, r) * dr_dx + sp.diff(df_dx, theta) * dtheta_dx

# 4. 「タテ(y)にちょっと進んだときの傾き」と「もう1回傾き（曲がりぐあい）」
df_dy = sp.diff(f, r) * dr_dy + sp.diff(f, theta) * dtheta_dy
d2f_dy2 = sp.diff(df_dy, r) * dr_dy + sp.diff(df_dy, theta) * dtheta_dy

# 5. タテとヨコの曲がりぐあいを足して、きれいに整理する！（これがラプラシアン！）
laplacian_polar = sp.simplify(d2f_dx2 + d2f_dy2)

print("変身した極座標ラプラシアン：")
sp.pprint(laplacian_polar)

4. 出てきた答えの意味を見てみよう！
Pythonロボットが出してくれた答えをきれいに並べると、こんな形になるよ。
幼稚園児でもわかる3つのパーツに分解すると、こうなるんだ！
 * \frac{\partial^2 f}{\partial r^2} （まっすぐ外へ進むときの曲がりぐあい）
   中心から外側へまっすぐ歩いたときの「お山・お皿」のぐあい。
 * +\frac{1}{r}\frac{\partial f}{\partial r} （丸く広がっていく分のオマケ）
   外に行くほど円がどんどん大きく広がるから、その「広がり分」を足してあげる調整パーツ！
 * +\frac{1}{r^2}\frac{\partial^2 f}{\partial \theta^2} （ぐるっと回るときの曲がりぐあい）
   同じきょりのまま円周をぐるっと歩いたときの「お山・お皿」のぐあい。（外に行くほど大回りになるから、r^2 で割って小さくするよ！）
これで、丸いケーキの上でも「どこがお山で、どこがお皿か」がバッチリ測れるようになったね！
