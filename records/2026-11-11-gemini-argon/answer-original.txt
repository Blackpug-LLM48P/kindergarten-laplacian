ラプラシアン（\Delta）とは、一言でいうと「まわりのお友だちの平均と、自分との差（どれくらい自分がボコッと出っ張っているか・凹んでいるか）」を測る虫メガネです。
四角いジャングルジム（直交座標 x, y）から、まわるメリーゴーランド（極座標 r, \theta）に乗り換えたときに、この虫メガネの形がどう変わるのかを「3つのステップ」と「Python」で見てみましょう！
ステップ1：四角いマス目（x, y）の世界
四角い部屋では、「右・左（x方向）の坂の曲がり具合」と「前・後ろ（y方向）の坂の曲がり具合」を足すだけです。
ステップ2：メリーゴーランド（r, \theta）に乗り換える
メリーゴーランドでは、場所を「中心からの距離 r（どんだけ外か）」と「角度 \theta（どんだけ回ったか）」で表します。
ここで、メリーゴーランドならではの2つの不思議（補正）が起きます。
 * 外に行くほど、横幅（バームクーヘンの切れ端）が広くなる！
   同じ角度 \theta だけ横に動くとき、中心の近く（r が小さい）では一歩が狭いですが、外側（r が大きい）に行くと一歩が r 倍に広がります。だから、回転方向の曲がり具合を測るときは、広がった分だけ r^2 で割ってあげる 必要があります（\frac{1}{r^2}\frac{\partial^2 f}{\partial \theta^2}）。
 * 外側のほうが「お隣さん」が多い！
   バームクーヘンは外側の輪っかほど長いため、内側の隣人よりも外側の隣人のほうがたくさんいます。その「外側の広さの違い」のせいで、まっすぐ外向きの坂道（\frac{1}{r}\frac{\partial f}{\partial r}）がオマケでくっついてきます。
ステップ3：合体！（極座標ラプラシアンの完成）
この3つ（「前後の曲がり具合」＋「外側の広さオマケ」＋「横の曲がり具合」）を合体させると、極座標ラプラシアンになります！
Pythonに泥臭い計算（連鎖律）をぜんぶやらせてみよう
大人が手で計算すると紙が真っ黒になる「微分のチェインルール（連鎖律）」も、Pythonの数式処理ライブラリ sympy を使えば、一瞬で上の式が導き出せます。
import sympy as sp

# 1. メリーゴーランドの変数 (r, theta) を用意する
r, theta = sp.symbols('r theta', real=True, positive=True)
f = sp.Function('f')(r, theta)

# 2. 「x方向」と「y方向」の小さな一歩を、(r, theta) の一歩に翻訳する魔法（ヤコビアン逆行列）
# ∂/∂x = cos(θ) ∂/∂r - (sin(θ)/r) ∂/∂θ
# ∂/∂y = sin(θ) ∂/∂r + (cos(θ)/r) ∂/∂θ
def d_dx(expr):
    return sp.cos(theta) * sp.diff(expr, r) - (sp.sin(theta) / r) * sp.diff(expr, theta)

def d_dy(expr):
    return sp.sin(theta) * sp.diff(expr, r) + (sp.cos(theta) / r) * sp.diff(expr, theta)

# 3. xで2回微分 ＋ yで2回微分 して、三角関数の公式でスッキリ整理（simplify）！
laplacian = sp.simplify(d_dx(d_dx(f)) + d_dy(d_dy(f)))

# 4. 結果を表示！
sp.pprint(laplacian)

実行結果：

d_dx(d_dx(f)) の中で、1回目の微分で出てきた \frac{\sin\theta}{r} などをもう1回 \theta で微分したときに、\sin^2\theta + \cos^2\theta = 1 が発動して、あの見慣れた \frac{1}{r}\frac{\partial f}{\partial r} がピョコッと顔を出します。
このまま3次元（球座標 r, \theta, \phi のお団子バージョン）への拡張や、バームクーヘンの面積要素（r\,dr\,d\theta）を使った発散定理からの直感的な導出も見てみますか？
