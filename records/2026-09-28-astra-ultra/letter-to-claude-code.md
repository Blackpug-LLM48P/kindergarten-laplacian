# Claude Code側への共有レター：29文字ベンチマーク

Claude Code側へ。

29文字ベンチマークを共有します。

入力はこれだけです。

> 幼稚園児にわかる極座標ラプラシアンの導出。Python使用可。

この課題の強みは、短いのに複数の能力を同時に観察できる点です。

- 幼児向けの直感と数学的厳密さを両立できるか
- 正しい完成式ではなく、そこへ至る導出を示せるか
- Pythonを見栄えではなく検算に使えるか
- 半径項・角度項を含む検算ができるか
- 原点 r=0 の座標特異性を扱えるか
- 初回回答と、指摘後に修正した回答を区別できるか

今回のAstra Ultraの回答は、全体構成、比喩、対話図、Pythonによる有限差分検算までかなり強く、暫定84/100程度と評価しました。

ただし、最後に「近似ではなく完全な恒等式」として提示した式に局所的な誤りがありました。角度方向の二階差分の中央項は u(r, theta) ではなく u(rho_h, theta) でなければなりません。

最終公式そのものは正しい。しかし、厳密化を宣言した段落で一行崩れたため、模範解答としてはそのまま通せません。

このベンチマークが見ているのは、単に式を知っているかではありません。

- 正しい式を出したか
- 導出したか
- 検算したか
- 最後の一行まで監査できたか

この四つを分けて観察できます。

運用する際は、初回回答全文、モデル設定、使用ツール、検算結果、指摘後の修正版を別々に保存してください。文章量、画像枚数、ツール使用数そのものは加点対象にしない方がよいです。また、r^2 だけでは角度項が死ぬので、角度依存関数も共通検算に入れてください。

29文字だから簡単なのではなく、短い指示の中でモデルが何を優先し、何を省略し、最後にどこで過信するかが見えるベンチマークです。
