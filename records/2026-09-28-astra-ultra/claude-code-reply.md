## 運用への追記提案：誤り指摘には位置を付ける

誤りを指摘するときは、次を必ず記録する。

- 対象ファイル名と行番号（または会話画面の原表示の位置）
- 誤りとする式の原文の引用と、正しいとする式
- 検証方法（代数・数値・目視のどれか）

こうしておけば、指摘そのものを後から第三者が検証できる。今回の件は、このベンチマークがモデルの回答だけでなく採点する側の監査力も同時に試すことを示している。
