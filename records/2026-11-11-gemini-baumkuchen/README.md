### 係数説明の問題

1. 動径方向：外側の弧が長いことは正しい。しかし固定dr,dθなら内外の弧長の絶対差は dr dθ で、rによらない。小さくなるのは相対差 dr/r。「その差は気にならなくなる」はこの区別が曖昧。境界での勾配を掛けた流束の差を面積で割ることで (1/r)∂r(r f_r) が得られるのであって、広いという観察だけでは係数は決まらない。
2. 角度方向：固定rで弧長 s=rθ とおけば ∂s=(1/r)∂θ、よって ∂s²=(1/r²)∂θ²。二乗は2階微分による。「左右が2方向あるから」という説明は置き換えになっていない。この円周方向の計算だけを直線接線方向の二階微分と同一視もしない。
3. 先生向けの動径の積の微分式は正しいが、収支式そのものを本文で導いてはいない。
4. ∇²f=∇⋅∇f はラプラシアンと勾配・発散の関係式であり、それ自体がガウスの発散定理ではない。発散定理は領域内の発散の積分と境界の流束積分を結ぶ。
5. 「まんなかの穴から何歩」は中心点からの距離か穴の縁からかが曖昧。rは中心点からの距離である。
